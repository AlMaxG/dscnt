Конфигурация источников и CORS

Режимы загрузки:

1. 🧪 Отладка в песочнице (Sandbox) — Для среды AI Studio

Работает напрямую внутри контейнера песочницы через внутренний серверный шлюз. Загружает оригинальную страницу Ситилинк с автоматическим разрешением анти-бот защиты и кэшированным снапшотом. Не требует установки расширений в браузер.

2. 🐵 Юзерскрипт (Tampermonkey) — Для локального браузера

Отправляет запрос через GM_xmlhttpRequest расширения Tampermonkey (скрипт citilink-bridge.user.js). Обходит CORS напрямую из браузера без сторонних прокси-серверов.

3. ⚡ Прямой запрос

Отправляет прямой браузерный fetch() запрос к citilink.ru без прокси. Требует наличия расширения «Allow CORS» или флага в браузере.
